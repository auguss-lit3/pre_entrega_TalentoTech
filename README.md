# pre_entrega_TalentoTech

Lite Coffee

## Descripción
Lite Coffee es un sitio web desarrollado para una marca de cafetería ficticia. Hecho como una forma de expandir el alcance de la marca, principalmente para presentar sus productos y tener una forma de contactarse con la marca.
El sitio cuenta con una presentación de la marca, un catálogo de productos, reseñas de clientes y un formulario de contacto.

## Tecnologías utilizadas
HTML5: utilizado para darle una estructura al contenido del sitio.

CSS3: utilizado para diseñar la interfaz, definir los colores, las tipografías y los efectos visuales.

Flexbox: utilizado para organizar el encabezado, la sección de inicio y las tarjetas de productos.

CSS Grid: utilizado para distribuir las tarjetas de reseñas.

Media Queries: utilizadas para adaptar el diseño a pantallas de diferente resolucion.

Google Fonts: utilizado para incorporar las tipografías Slabo 13px y Fleur De Leah.

Formspree: utilizado para procesar los mensajes enviados desde el formulario de contacto.

Git y GitHub: utilizados para el control de versiones y el alojamiento del proyecto mediante GitHub Pages.

## Características

- Navegación entre las diferentes secciones del sitio.
- Presentación de la marca con texto, imagen y acceso al catálogo.
- Catálogo de productos con imágenes, descripciones y precios.
- Sección de reseñas de clientes organizada con CSS Grid.
- Formulario de contacto conectado con Formspree.
- Efectos visuales al pasar el cursor sobre determinados elementos.
- Diseño adaptable mediante Media Queries, con ajustes específicos para pantallas de hasta 500 píxeles de ancho.

## Cómo ejecutar el proyecto
1 - Clonar el repositorio o descargar sus archivos.

2 - Mantener las imágenes dentro de la carpeta img, respetando los nombres utilizados en el HTML.

3 - Abrir index.html en un navegador web.

El formulario de contacto utiliza Formspree para procesar los mensajes enviados.
